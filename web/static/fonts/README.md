# Sampling guide font

`DejaVuSans.ttf` is the unmodified DejaVu Sans version 2.35 distributed with
Matplotlib. It is embedded in the sampling guide so Greek letters and mathematical
symbols remain readable without an operating-system font dependency.

SHA-256: `3fdf69cabf06049ea70a00b5919340e2ce1e6d02b0cc3c4b44fb6801bd1e0d22`.

The original copyright and redistribution terms accompany the font in
`LICENSE_DEJAVU`. This font is only used for printed sampling instructions;
generated personal handwriting continues to use the selected handwriting engine.
