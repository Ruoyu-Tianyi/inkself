# 长文与数学公式

使用已核对的字迹档案，在网页选择“样本习惯适配”或“原稿字形保真”。两种方式均可处理最多 20,000 字符；少样本神经模型保留 3,000 字符上限。普通连续单词最多 32 字符，公式另行解析，不受这一单词限制。

## 输入方式

勾选“启用数学公式”。正文保持英文和数字；行内公式放在 `$...$`，独立公式放在 `$$...$$`。也支持 `\(...\)` 和 `\[...\]`。公式会按结构排版，不会计算答案或判断等式是否正确。

```text
The return is $\mathrm{ROIC}_{t}=\frac{\mathrm{NOPAT}_{t}}{\mathrm{IC}_{t}}$.

$$x_{i_j}^{2}+y_i^2=r^2$$

$$\left\{\left[\frac{\alpha_{i,j}+\beta^2}{1+\sqrt{x_i^2+y_i^2}}\right]^2+\gamma\right\}$$

$$\sigma^2=\frac{1}{n}\sum_{i=1}^{n}\left(x_i-\mu\right)^2$$

$$\int_0^1 x^2\,dx=\frac{1}{3}$$

$$H_{i,j}=\frac{\partial^2 f}{\partial x_i\partial x_j}$$
```

支持上下标及嵌套上下标、嵌套分式、带根指数的根号、圆/方/花括号与可伸缩括号、求和/乘积/积分及上下限、常用希腊字母和函数名。`\mathrm{...}` 可写财务缩写，`\text{...}` 可加英文标签。未知命令会明确拒绝。

这是一套有限的数学输入语法。矩阵、分段函数、对齐环境、宏、完整 LaTeX 文档、中文正文和手写图片公式识别尚未实现。单个公式最多 2,000 字符、16 层嵌套、1,000 个语法节点；不执行 TeX、文件读取或代码。特别长的公式请拆成多条独立公式。

## 数学字形来源

已有字母、数字和符号优先使用已核对的个人档案。未采集的希腊字母、括号和数学运算符，可在明确勾选“使用配套手写数学字形”后使用。配套路径参考样本的字高、笔画和倾斜，**其具体写法没有从个人样本学得**。网页和报告会列出用到的配套字形。

关闭该选项后，缺失字形会在排队前报错。补采样并建立对应字形后，后续渲染会优先使用个人版本。当前补采样入库仍是开发者流程，尚无逐个数学字形采集界面。

## 长文排版

先规划完整行的上沿、下沿和共同基线，再安排分页。高分式、积分上下限和上下标会撑开所在行，避免压到邻行。独立公式居中、作为整体分页；若超宽，最多缩到请求字号的 65%，并在记录中提示。再宽则要求拆式，不截断内容。

编号题号尽量与后续正文一起移动；段落跨页时尽量两边各保留两行。空间不足以满足全部约束时记录警告。这里尚未提供自定义页眉页脚、表格、目录、跨行等号对齐或出版级数学排版。

每页生成后即写入 PDF，不再把所有页面栅格同时留在内存。`layout.json` 记录每项的位置、行号、页码、基线、缩放和警告；`report.json` 记录公式结构、字形来源及人工核对状态。PDF 仍以手写图像呈现，不含可搜索的文字层。

## AI 的作用

已核对字迹档案的习惯适配、公式解析和分页可离线运行，不需要在线大模型或 API 密钥。选择少样本模型时仍会运行本地 VATr++。上传任意新样本后自动识别文字、定位字形、学习连笔和数学写法，是后续需要识别/生成模型与真人验证的工作；本轮公式支持不代表这项最终目标已完成。

## 批量复现

实验套件的 `preferences` 可添加 `math_enabled: true`、`allow_supplemental_math: true`。其余调用方式见 [可复现流程](experiment-workflow.md)。输入、字迹模型、解析器、配套字形、公式布局及分页代码均进入指纹，`layout.json` 也参加逐文件校验。数学字形、内容准确性和相似度仍应逐页检查。

本轮用已核对档案检查了 2 页复杂公式，以及 12,035 字符、11 页的正文与公式混排。120 项自动检查通过；两次完整运行的 2,000 个产物校验值一致，网页下载的公式 PDF 也与本地运行相同。逐页预览与布局检查未发现越界或漏项。这些结果只证明该档案与测试内容的流程可复用，不代表任意新用户、新字形或全部数学环境已通过验证。
