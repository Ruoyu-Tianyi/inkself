# Repeatable local handwriting comparisons

The experiment runner compares the reference renderer and an already fitted habit
adapter on the same text, page settings and seed. It never trains on test text.
The adapter still uses a raster glyph scaffold; this workflow does not establish
general handwriting cloning or similarity to the writer.

## Prepare reviewed inputs

Use a visually reviewed reference bank and fit a model with
`scripts/fit_habits.py`. See [habit-adapter.md](habit-adapter.md). Freeze those files
before deciding which generated version looks best. If a word is to be excluded
from fitting, supply `--exclude` to the fitter first. An exclusion in a test suite
does not remove a word from an existing model; preflight rejects a model that
still contains it.

Save a private suite such as `.local/experiments/suite.json`:

```json
{
  "preferences": {"size": 16, "line_spacing": 1.6, "ink": "#263d57"},
  "excluded_words": ["sunlight"],
  "cases": [
    {"id": "new-prose", "title": "New prose", "text": "Gentle sunlight fills the room.\nWe finish our work before lunch."},
    {"id": "repeat-words", "title": "Repeated words", "text": "little little little\nminimum minimum minimum"},
    {"id": "numbers", "title": "Digits and symbols", "text": "0123456789 9876543210\n27+58=85 120-45=75\n0.25 24.50 15%"}
  ]
}
```

All requested characters must exist in the bank. Missing characters, invalid
models, invalid page settings and unsafe case names fail before any output is
created. Case IDs use letters, digits, hyphens or underscores. Keep each text at
20,000 characters or fewer. The compositor measures visible ink edges and varies
word gaps using frozen sample statistics; line breaks are retained. Use visible words and line breaks rather than
spaces for layout. Pages that cannot fit an individual word fail explicitly.

The optional top-level `word_spacing` object stores the JSON result of
`web.runtime.word_spacing.fit_word_spacing(...)`. Supply selected English source
line images and reviewed word coordinates for the strongest evidence. The model
records measured gaps, evidence labels and source hashes. It is copied into the
suite snapshot and each request, so replay does not need the original photos.
Without this object the compositor uses explicitly labeled conservative spacing,
not a claim that the writer's word gaps were learned. Each layout records realized
boundary gaps, image crops and a fingerprint covering text, rasters, settings,
spacing statistics and layout code. A fixed seed reproduces the same spacing.

## Generate a comparison

On Windows, from the repository root:

```powershell
.local/model-env/Scripts/python.exe scripts/run_handwriting_experiment.py --bank .local/my-bank/bank.json --model .local/my-model.json --suite .local/experiments/suite.json --output .local/experiments/run-01 --seed 42 --snapshot-inputs
```

On other systems, use the Python interpreter where the web dependencies are
installed. `--modes reference` can run without `--model`; by default both
`reference,learned-habits` are generated. These modes run offline and do not need
the VATr++ weights. The output directory must be new or empty. Completed and
failed partial runs are never overwritten; use a new run directory.

Open `review.html` in the resulting folder to compare every case side by side.
Each case/mode contains a PDF, page previews and word-level provenance. Check the
actual PDF pages too: the previews are generated by the compositor, not an
independent PDF renderer. Review text, punctuation, clipping, joins, repeated
letter variation and similarity to the source. Record the writer's feedback
separately; software tests alone cannot establish these judgments.

## Reproduce and audit

`manifest.json` contains the full normalized suite, seed, bank/model hashes,
reference-image hashes, fitter/renderer code hashes, Python/package versions,
output hashes and training-overlap diagnostics. `run_fingerprint` identifies the
content, code and runtime settings independently of machine-local file paths and
elapsed time. Deterministic PDFs, images and provenance reports are hashed;
request files and worker logs containing runtime paths are excluded. Differences
in dependency versions or platforms may change results and the fingerprint.

Review overlap before making a claim about generalization. A word can be absent
from model fitting yet present in the reference bank; the reference renderer can
reuse it. The habit model still has access to source glyphs and shared sample
statistics. The runner lists these overlaps and directly unobserved letter pairs,
and always labels text accuracy and writer similarity as unverified. Requested
exclusions found in training stop the run rather than being treated as held out.

With `--snapshot-inputs`, only the reviewed bank manifest, referenced images and
fitted model are copied into `inputs/`; unrelated source-folder files are omitted.
The manifest's `replay_inputs` paths are relative to the run folder. Move the whole
folder and rerun with the same code/runtime:

```powershell
.local/model-env/Scripts/python.exe scripts/run_handwriting_experiment.py --bank .local/copied-run/inputs/bank/bank.json --model .local/copied-run/inputs/habit-model.json --suite .local/copied-run/suite.json --output .local/experiments/replay-01 --seed 42
```

Use the seed and modes saved in the original manifest. Compare fingerprints and
`artifact_sha256` entries. No re-fitting is needed to reproduce a frozen model;
to reproduce fitting, retain its reviewed bank, the fitter revision and exclusion
arguments as well. Alignment diagnostics generated during fitting remain useful
review evidence and should be archived alongside the run when available.

Snapshots, suites and outputs can identify a writer. Keep real samples under
ignored `.local/` storage. Commit only generic code, documentation and synthetic
tests; the runner does not publish anything or upload samples.

## Included suite and replay checks

`examples/evaluation-suite.json` contains planning prose, a narrative/repeated-word case, and grouped numbers/time/alphanumeric/operator cases. It contains no personal images. Its declared excluded words must be absent from the fitted training set; preflight fails on leakage, unsupported characters, overlong words or pale ink.

Compare `run_fingerprint` and every entry under `artifact_sha256` between two manifests to verify reproduction. Elapsed duration and output paths are excluded from deterministic identity; changing code, model, input bytes or package/runtime versions changes provenance. Expected source hashes in web jobs and experiment requests reject inputs changed during queueing, snapshot copying or between cases, so one run cannot silently mix model versions.

Visual review must still inspect actual PDF pages for letters, punctuation and margins. Hash equality and software tests establish reproducibility, not OCR correctness or personal similarity. The initial reviewed transcription and glyph bank still require preparation; uploading any arbitrary paragraph does not yet automate that step.
