# Inkself 产品路线与验证状态

目标：普通用户自然抄写一段指定英文与数字，上传后保存个人字迹风格，再输入新内容生成手写文档。当前提供本机网页、Windows 桌面便携版，以及内置 CPU 推理运行时的安装版，处于单用户内测与真人验收阶段。

## 已实现

- 固定采样内容、图像上传、质量提示、文字行切分与人工确认。
- 可选数学/希腊字母采样及独立行类型保存；数学原图不混入英文风格编码，字形定位与核对仍需后续处理。
- 按可见墨迹测量词距，保存可靠间距分布、证据来源和相关变化；有界、可复现的变化参与换行与分页。
- 本地多档案、风格缓存、字号/行距/墨色偏好、队列和刷新后查看任务。
- VATr++ 预训练生成器的真实离线 CPU 推理，生成新词和数字。
- 原图对照、A4 预览、PDF、历史作品与真人评价。
- 已核对档案的长文生成、行基线规划、题号/段落/公式解释的分页保留，按页输出和位置记录。
- 数学模式：上下标、分式、根号、嵌套括号、求和、积分、偏导与希腊字母；未采集数学字形使用显式允许的配套路径。
- 数学笔画：已采样括号优先沿其中心线重绘，根号勾与上横线连续绘制；按样本笔宽及倾斜调整，轻微变化可用相同种子复现。结构绘制不等于学习到了个人根号写法。
- Markdown 本机导入：标题、段落、列表、强调可见文字及公式转换为可编辑内容，保留原文、哈希和转换提示；普通代码块与不支持结构明确拒绝。
- 独立逐字采样引擎，保留作辅助与对照，不与网页模型混同。
- Windows 目录式 EXE：独立窗口、进程随窗口退出、重复启动隔离、档案导入、外部模型连接、干净便携 ZIP 与文件校验清单。
- Windows 安装器：当前用户安装、快捷方式、升级/卸载保留数据；独立 InkselfAI.exe 自带 CPU Torch，无需用户安装 Python。首次点击准备模型，下载固定版本并校验，随后离线运行。

## 验证及限制

最近一次本地 unittest 共 235 项：234 通过，1 项实际符号链接测试因 Windows 权限跳过（重解析点拒绝逻辑另有检查）。覆盖桌面生命周期、安装器输入清单、数据路径、档案导入、模型准备及校验、Markdown 转换、公式笔画、词距统计、数学采样、排版和原有生成流程。每次安装包的首次启动、联网准备、升级和卸载仍需独立验收，单元测试数量不是安装体验或字迹质量结论。

合成参考样本已通过实际模型推理及缓存复用检查；独立 InkselfAI.exe 已用本地测试档案验证正常退出、完整结果、确定性词图和任务日志，缺模型时返回失败并保留错误。网页已试跑上传、确认、生成、预览和 PDF，检查过桌面/手机布局及 PDF 页面。默认神经模型的文字与符号仍需核对；习惯适配已增加数字/符号、小字号标点、结构化公式和长文排版检查。

2026-10-23 已在本机实际安装完整安装器，清洁系统 PATH 下启动原生窗口、自动发现独立 AI 引擎，完成真实少样本推理、个人档案导入、Markdown 上传及双页数学 PDF 下载。模型准备检查预填 48 个已核对公开文件，由程序实际下载缺失配置后验证全部 49 项；这不等同于在空缓存下完整下载全部模型的网络验收。另已验证卸载保留个人数据；数学与 Markdown 冻结样例重放的 177 个产物哈希完全一致。

**真人测试正在进行，尚无相似度或全面内容准确性通过结论。** 尚未接入独立 OCR，不以任务成功、日志或下载替代可见内容核对。CI 配置包含 Linux/Python 3.10 和 3.12，远程矩阵结果须单独核实。

## 后续工作

1. 收集授权真人样本与未见测试内容，分别记录相似度、自然程度、数字和字符错误，固定验收集。
2. 在同一测试集比较候选生成模型，决定保留、替换或适配当前模型；目前未宣称 VATr++ 是最优方案。
3. 接入独立识字核对、错误重试与质量门槛，优先处理数字和符号。
4. 自动完成样本转录对齐、字形定位、连笔统计和个人数学字形建档，减少当前高保真流程中的开发者工作。
5. 在未安装 Python 的干净电脑与不同网络下完成安装、断点续传、升级/卸载和数据保留验收；随后完善签名和更新流程。
6. 核实模型、上游代码、字体原型和训练数据的使用条件，达到质量门槛后再正式发布。公共安装器目前不内嵌这些模型资产，离线全量包仅供内部测试。
7. 完成远程认证、私有存储、持久队列、配额与成本记录，再做云端多用户内测。

中文、矩阵/对齐等数学环境、图片公式识别和完整段落级连续生成仍需分别扩展与验证。数学结构支持不代表未采样希腊字母的个人写法已经学会。当前没有公共线上服务，也不宣称最终产品目标已经完成。
