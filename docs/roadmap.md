# 实施与验收

## 已完成的准备

- 创建 AI skill 入口与操作边界。
- 实现本地档案创建、样本复制与哈希、转录归档、偏好更新、列出与读取。
- 添加输入校验与行为测试。
- 分离公开代码与个人样本；不捆绑 TypeScribe 模型或个人作业。

## 下一步 MVP

优先实现定位采样页和单页字形渲染，先做一次端到端实验，再扩大到全字符集。用户必须提供真实样本后才能测量相似度，当前没有用户样本，因此没有“模仿成功”的实验结果。

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| A 采样 | 可打印英文/数字/符号采样 PDF、图片质量报告 | 格位可定位，空格和缺字可见，转录可纠错 |
| B 提取 | 多变体 glyph 库和来源映射 | 可追溯每个字形，错误映射不进入可信库 |
| C 渲染 | 相同 profile 的 SVG/PDF、缺字报告 | 字母数字风格一致，缺字明确失败，符号和上下标正确 |
| D 增强 | 连字/词库或可选生成模型 | 在相同测试集上比 C 更自然且不降低内容准确率 |

## 关键测试

1. **身份与数字**：独立测试长数字串、相近字符 0/O、1/l/I、5/S、8/B。将漏字、错字和改变小数点视为阻断性问题。
2. **公式**：百分号、负号、除号、括号、上下标不丢失；验收源文本、可见字形与映射日志，不能只看 PDF 的隐藏文本。
3. **整页**：每页渲染为图像检查裁切、重叠、行间冲突和过密；不能只抽查首页。
4. **风格**：由样本主人对原字迹、字形库版、可选模型版做同内容盲评。记录主观相似度与数字可读性，暂不设没有实测支持的商业指标。
5. **复用**：同一 profile + seed + 引擎版本得到相同布局；本次偏好覆盖不静默修改档案默认值。
6. **档案管理**：拒绝路径穿越、重复 ID、未知偏好键和越界值；幂等归档同一张图；转录非 UTF-8 时不写入半成品。

## 开发估算

需要先完成一个用户、少量字形的技术验证，才能给出可信工期和模仿质量承诺。可把阶段 A–C 作为小规模本地工程，阶段 D 作为独立研究任务；不要把二者合并成“一段照片即可学会个人字迹”的第一版承诺。
