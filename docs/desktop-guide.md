# Windows 桌面便携版

解压完整的 `Inkself-windows-x64.zip` 到有写入权限的文件夹，双击 `Inkself.exe`。不需要为基础程序安装 Python。请保留同目录的 `_internal`，不要单独移动 EXE，也不要直接在 ZIP 内启动。程序尚未数字签名，不需要管理员权限，不建议放到 Program Files。

程序以独立 Windows 窗口显示现有工作室，通过回环地址运行本机服务，不向公网提供服务。需要已安装的 Microsoft Edge WebView2；若组件不可用，会显示浏览器模式控制窗口。浏览器模式下须保留控制窗口。

## 数据与退出

字迹档案、作品、浏览器状态和设置保存在 EXE 旁边的 `data` 文件夹；备份时先关闭程序，再复制该文件夹。便携版升级时解压到新目录，再复制原 `data`，不要用空数据覆盖旧档案。可通过 `--data-dir` 或 `INKSELF_DATA` 使用另一数据目录。

同一数据目录只允许一个桌面实例。桌面版自动选择空闲本机端口，不会接管旧版 8765 服务；关闭窗口会停止自身服务和工作进程。生成进行中退出会中断任务，下次启动会标记为中断，可重新提交。

## 导入原来的个人字迹

在桌面菜单选择 **文件 → 导入旧版字迹档案…**，选择旧项目的 `.local/web-data` 目录（其下包含 `profiles`）。程序检查并复制档案，保留原文件；相同 ID 已存在时跳过，不覆盖。

导入包括原始样本、已核对字形库、习惯参数及偏好，不包含历史作品。原来的历史 PDF 继续保留在旧目录；新生成会使用桌面版的新路径。

选择 **样本习惯适配** 或 **原稿字形保真** 后，已准备的档案可离线生成英文、数字和数学公式。数学输入方式见 [数学与文档指南](math-and-documents.md)。

## 可选少样本神经模型

基础 EXE 不包含 PyTorch、VATr++ 权重或任何人的笔迹。菜单 **模型 → 连接本地少样本模型…** 可连接已通过 `setup-web.ps1` 安装的本地环境：

1. 选择原项目 `.local/model-env/Scripts/python.exe`。
2. 选择原项目 `.local/vendor/vatrpp` 文件夹，其中应包含 `model.safetensors`。

程序保存路径并重启自己的服务，原项目文件保留。连接的是外部环境；移动程序到另一台电脑时，须在新电脑安装/连接模型环境，旧电脑的绝对路径不可复用。当前不会自动下载或安装神经模型。

**干净基础包不是任意新用户开箱克隆字迹的完整产品。** 新用户上传图片后，若没有连接神经模型，也没有导入已准备的字形/习惯档案，暂时只能采样与检查，不能完成生成。个人字形自动建档仍是后续工作。

## 排错与构建

启动或生成失败时查看 `data/logs` 与对应任务的 `worker.log`。数据目录不可写时，把整个程序文件夹移到有写入权限的位置。程序未提供自动更新或安装器；公共程序 ZIP 不携带用户数据、本机模型设置或模型权重。

维护者可在项目环境安装 `desktop-requirements.txt`，然后执行：

```powershell
python scripts/build_desktop.py --output dist
```

输出目录包含程序目录、ZIP、依赖许可和完整文件校验清单；构建遇到已有输出会停止，避免覆盖。基础包与 Python、PyInstaller、pywebview 的打包依赖独立于可选神经模型。桌面版不会提升当前字迹生成器的准确性，所有结果仍需人工核对。
