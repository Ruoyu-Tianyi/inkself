# Windows 安装版与便携版

普通用户推荐在 Windows 10/11 x64 上运行 **Inkself-Setup.exe**。安装版包含独立的本地 CPU AI 推理引擎，无需安装 Python 或填写 API 密钥。首次启动点击“一键准备本地 AI”，联网获取约 580 MB 固定版本模型资产；下载会校验文件，失败后可继续。之后按引导抄写、上传照片、检查文字行，再生成并核对试写。

安装默认不需要管理员权限，程序安装到 `%LOCALAPPDATA%/Programs/Inkself`，提供开始菜单和可选桌面快捷方式。个人档案、作品和模型保存在 `%LOCALAPPDATA%/Inkself/data`，升级及卸载保留这些数据。可在“写下新内容”直接 [导入 Markdown](markdown-import.md)。AI 参与的具体环节与当前质量边界见 [首次使用流程](ai-workflow.md)。

## 便携基础包

解压完整的 `Inkself-windows-x64.zip` 到有写入权限的文件夹，双击 `Inkself.exe`。不需要为基础程序安装 Python。请保留同目录的 `_internal`，不要单独移动 EXE，也不要直接在 ZIP 内启动。程序尚未数字签名，不需要管理员权限，不建议放到 Program Files。

程序以独立 Windows 窗口显示现有工作室，通过回环地址运行本机服务，不向公网提供服务。需要已安装的 Microsoft Edge WebView2；若组件不可用，会显示浏览器模式控制窗口。浏览器模式下须保留控制窗口。

## 数据与退出

安装版的数据目录为 `%LOCALAPPDATA%/Inkself/data`；便携版为 EXE 旁边的 `data`。字迹档案、作品、浏览器状态和设置均在对应数据目录中；备份时先关闭程序，再复制整个目录。安装版的一键下载模型在数据目录下的 `models/vatrpp`；便携版模型默认在 EXE 旁边的 `models/vatrpp`，需另行备份。便携版升级时解压到新目录，再复制原数据与模型，不要用空数据覆盖旧档案。可通过 `--data-dir` 或 `INKSELF_DATA` 使用另一数据目录。

同一数据目录只允许一个桌面实例。桌面版自动选择空闲本机端口，不会接管旧版 8765 服务；关闭窗口会停止自身服务和工作进程。生成进行中退出会中断任务，下次启动会标记为中断，可重新提交。

## 导入原来的个人字迹

在桌面菜单选择 **文件 → 导入旧版字迹档案…**，选择旧项目的 `.local/web-data` 目录（其下包含 `profiles`）。程序检查并复制档案，保留原文件；相同 ID 已存在时跳过，不覆盖。

导入包括原始样本、已核对字形库、习惯参数及偏好，不包含历史作品。原来的历史 PDF 继续保留在旧目录；新生成会使用桌面版的新路径。

选择 **样本习惯适配** 或 **原稿字形保真** 后，已准备的档案可离线生成英文、数字和数学公式。数学输入方式见 [数学与文档指南](math-and-documents.md)。

## 可选少样本神经模型

基础 EXE 不包含 PyTorch、VATr++ 权重或任何人的笔迹。菜单 **模型 → 连接本地少样本模型…** 可连接已通过 `setup-web.ps1` 安装的本地环境：

1. 选择原项目 `.local/model-env/Scripts/python.exe`。
2. 选择原项目 `.local/vendor/vatrpp` 文件夹，其中应包含 `model.safetensors`。

程序保存路径并重启自己的服务，原项目文件保留。连接的是外部环境；移动程序到另一台电脑时，须在新电脑安装/连接模型环境，旧电脑的绝对路径不可复用。完整安装版则内置 AI 引擎，并提供一键准备模型，无需这一外部环境连接步骤。

**基础便携包需要另行连接生成引擎或导入已准备的字形档案。** 完整安装版完成首次模型下载后，新用户可以直接试写英文、数字及支持的标点；高相似度效果仍待真人验收。个人字形自动建档仍是后续工作，复杂公式目前需要已准备的字形档案。

## 排错与构建

启动或生成失败时查看数据目录的 `logs` 与对应任务的 `worker.log`。便携版数据目录不可写时，把整个程序文件夹移到有写入权限的位置。当前没有自动更新；程序 ZIP 和默认安装器不携带用户数据、本机模型设置或模型权重。

维护者可在项目环境安装 `desktop-requirements.txt`，然后执行：

```powershell
python scripts/build_desktop.py --output dist
```

输出目录包含程序目录、ZIP、依赖许可和完整文件校验清单；构建遇到已有输出会停止，避免覆盖。基础包与 Python、PyInstaller、pywebview 的打包依赖独立于可选神经模型。桌面版不会提升当前字迹生成器的准确性，所有结果仍需人工核对。

完整安装器先构建 `scripts/build_ai_runtime.py`，再用 `scripts/build_installer.py --app ... --ai-runtime ... --compiler ... --output ...`。安装输入必须是带完整校验清单的干净程序目录；不得将个人 `data` 放入发布包。可选 `--model` 仅用于本地离线内部测试，不是已完成模型公开分发许可核实的声明。
