# 网页产品推进状态

主产品改为网页，Skill 保留为未来自动化入口。项目仓库名称暂保留，不影响网页使用。

## 已推进到真人内测的部分

- 真实 VATr++ 生成器离线 CPU 推理，不使用通用字体冒充个人字迹。
- 指定自然段采样、PNG/JPEG/WebP 上传、质量提示、文字行提取及逐行确认。
- 本地多档案、个人风格缓存、任务队列与状态恢复、英文/数字试写。
- 原图对照、A4 图片预览、PDF 导出、历史作品和真人评价。
- 仅本机单用户运行，上传和档案删除边界明确。

## 本轮验证及其限制

合成印刷样本通过图片处理与实际模型推理，从参考段落生成新词和数字。该测试不含真人样本，不能证明模仿相似度。扩展样本中，英文句子及数字已实际生成，但百分号、加号的形状不够清晰；内容准确性尚未通过，不应宣称所有符号生成正确。本地 28 项 unittest 全部通过，覆盖既有引擎与网页接口、状态门禁、重启中断、偏好持久化和浅色墨迹保护；浏览器完成上传、切行审核、真实生成及预览链路，检查桌面/手机宽度下无横向溢出。实际 PDF 已逐页渲染检查。真人评价、独立 OCR 准确性、多用户隔离、云端 GPU 部署未完成，不能称最终产品已完成。

## 真人验证后继续

1. 收集多个新用户授权样本与未见测试内容，固定验收集；优先定位数字错误和风格不相似的情况。
2. 同一测试集比较 VATr++、DiffusionPen/One-DM 等适用候选；按真实表现决定继续使用、替换或适配模型。
3. 接入独立识字核对与错误重试；在风格和内容均有证据后确定质量阈值。
4. 完成远程认证、私有存储、持久任务队列、取消/配额与成本记录，再进行云端小范围内测。
5. 核实模型和数据的商业使用条件；达到验收门槛后再正式发布。

这次停点应是可操作网页上的真人字迹验收，不应以空白 UI 或占位模型作为完成。
