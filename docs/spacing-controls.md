# 间距与书写节奏

[返回中文说明](../README.md) · [English overview](../README.en.md#spacing-and-writing-rhythm-current-source)

本功能随当前源码提供。已发布的 `0.4.0-rc.1` 安装包尚不包含这些控件，需运行更新后的源码；后续安装包是否包含此功能，以对应发布说明为准。

## 使用方法

1. 在试写页选择个人字迹和生成模式。
2. 选择自然、工整、紧凑或宽松间距风格。
3. 展开微调项，按需调整比例和变化幅度。手动修改后显示为自定义。
4. 点击“生成试写”，检查换行、公式、跨页位置及可读性，然后导出 PDF。

调整适用于下一次生成；不会修改已有作品。生成时会将设置保存到作品，并更新所选档案的偏好。重新选择档案或打开历史作品时会恢复对应设置；没有这些设置的旧档案使用默认值。

## 预设

| 风格 | 用途 |
| --- | --- |
| 自然 | 保留默认间距和自然变化，适合作为调整起点 |
| 工整 | 减弱间距变化与词语上下起伏，行间稍宽 |
| 紧凑 | 缩小各类间距，减少行段留白 |
| 宽松 | 增大各类间距和行段留白，略增强自然变化 |
| 自定义 | 保存手动调整后的组合 |

## 微调项

| 控件 | 含义 |
| --- | --- |
| 字母间距 | 同一词内字母之间的间距；只用于习惯适配、字形保真 |
| 词间距 | 相邻词的可见笔画之间的距离 |
| 行间距 | 相对于基础行距的比例；仍保留避免笔画和公式相撞所需的空间 |
| 段落间距 | 段落之间的留白；不会凭空把连续文字分成新段落 |
| 数字间距 | 数字串内部的间距；只用于习惯适配、字形保真 |
| 符号间距 | 符号周围的水平间距；只用于习惯适配、字形保真 |
| 词语上下起伏 | 同一行内词语相对基线的高低变化；不是行间距 |
| 间距变化 | 疏密变化的强弱；不改变字形本身的变化强弱 |

间距比例 `100%` 表示默认水平；低于 `100%` 更紧密，高于 `100%` 更疏朗。上下起伏或间距变化设为 `0%`，可关闭对应的额外变化，原始字形中的不规则仍会保留。由于像素取整、公式结构及最小安全间距，小幅调节不一定在每个位置都形成肉眼可见差异。

“间距变化”在 `0–100%` 之间调节已有的词间距和数字间距变化；对于原本固定的字母、符号、行和段落间距，额外变化从 `100%` 以上开始。词语上下起伏独立控制，数值越高，允许的高低变化越大。

## 模式与可复现性

普通文档和作业答卷共用这些偏好。字号、基础行距、墨色仍单独设置；改变字号也会改变实际像素间距。

默认神经模型和模型校正模式生成完整词图，不能可靠地在词内任意移动单个字母、数字或符号。因此这些模式禁用相应内部间距控件，其余排版控件仍可使用。使用已核对字形档案的习惯适配、字形保真模式可调整内部间距。调整词内间距时，受影响的原稿词图会改用已核对字形重新组合，原有连笔可能变化；例如只调数字间距，不会因此重组纯英文原稿词图。

这些控件提供可复现的偏好调整，不构成“已从个人样本学会全部间距习惯”的结论。它们不改写输入内容，也不检查算术或自动纠错。相同输入、档案、模型、代码、设置和随机种子可复现结果；更改影响宽度或高度的设置可能改变换行、页数和跨页位置，导出前仍需检查。
