# Markdown 导入

在“写下新内容”选择 **导入 Markdown 文档**，上传 UTF-8 编码的 `.md` 或 `.markdown`（最多 256 KiB，原文最多 100,000 字符）。程序在本机解析，填入可编辑正文；检查转换提示后选择字迹并生成 PDF。转换后的正文最多 20,000 字符，少样本神经模式单次仍最多 3,000 字符。

支持标题、段落、题号、列表、粗体/斜体的可见文字、引用、链接标签与行内代码文字。标题符号及强调标记不作为笔画写出，也不自动改变标题字号或正文笔画粗细；表格转换为分号分列的逐行文字并显示提示。图片只能保留替代文字并提示，不能变成手绘图；缺少替代文字时要求先补充。普通代码块、HTML、脚注及未闭合结构会明确报错。

数学公式保留 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`；`math`、`latex`、`tex` 围栏块转换为独立公式。含公式时，需要选择带有核对字形库的档案；未采样的希腊字母等仍需明确允许补充字形。更详细语法见 [数学指南](math-and-documents.md)。

原始 Markdown 文本、解析统计和转换提示保存在本机；生成任务还记录原文哈希以及导入后是否编辑，便于复查。解析器不执行文档中的指令、HTML或代码，不打开链接，也不读取链接指向的本地文件。

可使用仓库中的 [示例文档](../examples/handwritten-homework.md) 测试。当前输出保留内容顺序和段落结构，不是 Markdown 网页样式的逐像素复制；不会将粗体标记自动解释为重描笔迹。
