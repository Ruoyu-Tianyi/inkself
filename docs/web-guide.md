# Inkself 网页内测版

目标：用户自然抄写一段指定英文、数字并上传，生成新的词句。当前到达本机单用户的模型内测阶段，真人样本和相似度验收正在进行，尚无通过结论；尚未达到面向任何人的正式线上产品。

## 启动

普通用户使用 [完整 Windows 安装版](desktop-guide.md)，首次点击准备模型后即可使用本机工作室，无需配置 Python。以下命令说明面向从源码运行的维护者。

完成下文的开发环境安装后，双击仓库根目录 **Start Inkself.cmd**，浏览器打开 `http://127.0.0.1:8765`。若启动失败，查看 `.local/web-server.log`。默认只监听本机，不向公网开放，也不能直接让手机通过局域网访问。

停止后台服务：先核对 `.local/web-server.pid` 中的进程命令为本项目 uvicorn，再停止对应进程。不要直接结束占用其他服务的任意 Python 进程。

## 使用流程

1. “采集字迹”：自然抄写页面提供的五行英文/数字，保留平时词间距的变化，不要刻意写成相等。需要公式时，建议另外抄写五行数学符号、希腊字母及上下标示例；数学与英文分别成行，不熟悉的符号可跳过。使用深色笔、浅色纸，只拍自己的书写部分；可下载两页采样纸。
2. 命名档案并上传一张 JPG/PNG/WebP（20 MB、2400 万像素以内）。程序进行 EXIF 方向修正、背景归一化、适度倾斜校正及文字行切分。当前不支持整页任意透视、竖排或多栏照片；先保持拍摄平直。
3. 逐行选择“英文/数字”“数学/希腊字母”或“不使用”；印刷文字、断行和杂物不使用。至少保留一行英文/数字。英文模型只读取英文/数字行，数学行单独保留在档案中，仍需定位、核对和入库后才能成为个人数学字形；确认保存不代表相似度已通过。保存后可在“字迹与作品”选择“检查采样行”修改分类，后续试写使用更新后的英文行。
4. “写下新内容”：输入样本中没有出现的新英文/数字，或 [导入 Markdown](markdown-import.md)，再选择字号、行距和墨色。生成时记住该档案的字号、行距和墨色；少样本模型读取样本风格，生成新的词图，再排版成 A4 页；输出中的文字与数字必须逐字核对。公式需要切换到带有核对字形库的原稿保真或习惯适配模式。
5. 下载 PDF，记录内容是否正确、字迹相似度、自然程度和具体问题。作品及评价会保存在“字迹与作品”。刷新页面后可以继续查看任务。
6. 删除档案会删除关联样本、风格缓存、作品和评价；有任务在执行时会拒绝删除。

## 当前边界

- 少样本神经模式使用固定版本 VATr++ 预训练生成器，支持英文大小写、数字及模型字母表中的常用标点。非支持字符明确拒绝，不静默删掉；该模式暂不支持中文、等号、美元符号、结构化公式和上下标。最多 3,000 字符，连续单词最多 32 字符。
- 原稿字形保真与样本习惯适配模式可处理最多 20,000 字符，并支持 [结构化公式](math-and-documents.md)。这两种模式需要已核对的个人字形库；字形自动识别、入库和习惯拟合尚未成为新用户上传后的自动流程。
- 生成的是整词字图，可出现词内连笔；仍按词排版，不是完整段落级笔画连续生成。多个空格按普通词距呈现，保留显式换行。
- CPU 实测合成参考图生成三个新词/数字约 22 秒，时间随设备和内容变化。该结果证明推理可以运行，不证明本人相似度、全部字符或数字准确性通过。
- 尚未接入独立 OCR 自动核对。输出状态默认“待人工核对”，反馈不正确时记录错误，不伪称自动验证正确。
- 风格编码可保存为本地缓存，后续同档案复用；更改选中样本行会产生新的缓存，不执行个人模型训练。
- 本机单用户版本没有账号和远程身份隔离，不能直接改为 0.0.0.0 后当成多用户网站发布。云端需单独部署推理服务、认证、私有对象存储、配额与任务持久化队列。

## 从源码安装开发环境

Python 3.10–3.12。PowerShell 在项目目录运行 `./setup-web.ps1`（遵循本机执行策略，不要求关闭全局保护）。安装 CPU PyTorch、网页依赖及固定模型资产，下载中断可重新运行。模型权重约 561 MB，依赖还需额外磁盘空间。Windows 内测环境为 Python 3.12.14；其他平台先按下列方式设置后测试。

```sh
python -m venv .local/model-env
# Activate the environment for your platform, then:
python -m pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r web/requirements.txt -r web/runtime/requirements.txt
python scripts/setup_model.py
python launch.py
```

模型来源、许可与固定版本见 [model-notice.md](model-notice.md)。模型及上游代码在忽略的 `.local/vendor`，不会随本仓库推送。已使用授权个人样本开展本机测试；这些样本、私人测试内容及作品不随公开仓库发布，生成流程不向外部服务上传个人文件。

## 开发与测试

```sh
python -m unittest discover -s tests -v
node --check web/static/app.js
python -m uvicorn web.app:app --host 127.0.0.1 --port 8765
```

服务包含同源令牌检查、Host 校验、图像格式/大小限制、不可枚举随机 ID、生成队列上限、上传检查、任务中断恢复标记和生成结果下载白名单。数据默认 `.local/web-data`；可通过 `INKSELF_DATA` 改为自选本地目录。工作日志、报告和输入文本同样属于私人数据。

## 真人验收任务

使用自然书写的真实样本，首次提交约 50–100 个新英文单词及专门的数字测试（含 0/O、1/l、3/8 等易混形态）。对照原图和输入内容，分别记录：遗漏/新增/写错字符；字形、倾斜、间距是否像本人；数字是否与正文风格一致；换行和长文是否出现异常。不要只用生成次数或下载成功作为通过标准。

使用完整安装版时，当前应由本人完成的步骤是：点击准备模型、书写并上传样本、检查切分、评价相似度与文字准确性。无需安装 Python 或编写命令；从源码运行则仍需完成开发环境安装。
