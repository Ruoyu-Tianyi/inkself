# 首次使用与 AI 参与的步骤

完整安装版的目标操作顺序是：安装 → 一键准备本地 AI → 抄写并上传指定内容 → 检查文字行 → 生成新内容 → 核对并保存个人档案。用户不需要安装 Python、选择推理框架或填写 API 密钥。

安装器内置独立 CPU 推理引擎。首次准备从固定模型版本下载约 580 MB 资产，显示进度、支持断点续传并检查每个文件的 SHA-256；模型就绪后可离线生成。下载只获取公开模型文件，不发送个人笔迹、Markdown 或生成内容。

| 步骤 | 当前实现 | AI 是否参与 |
| --- | --- | --- |
| 照片整理与文字行切分 | 图像处理、质量提示、用户检查 | 当前不调用大模型 |
| 样本风格编码 | 从确认的文字行提取并缓存风格 | 本地 VATr++ |
| 新词与英文数字试写 | 预训练生成器推理，输出默认待核对 | 本地 VATr++ |
| Markdown 与公式结构 | 安全解析、可编辑正文、确定性公式排版；括号和根号按样本笔宽、倾斜适配 | 无需 AI |
| 已准备个人字形的高保真适配 | 已核对字形及统计习惯参数 | 无在线模型调用 |
| 自动建立高保真字形库和个人数学写法 | 尚未自动化，仍需开发者整理及核对 | 后续需识别、对齐与风格学习模型 |
| 独立 OCR 核对与自动纠错 | 尚未接入，当前由用户检查 | 后续独立识别模型 |

完整安装解决环境配置和操作门槛，并不等于已经解决任意短样本的高相似度克隆。新用户可以通过自然样本使用少样本模型；目前含复杂公式的个人字形适配仍要求已准备的字形档案。希腊字母和括号缺少个人采样时只能使用明确允许的补充字形。根号采用连续的算法笔画，已有括号尽量沿用个人字形的中心线；这些结构会适配笔宽和倾斜，但不能声称已学会本人书写数学结构的动作习惯。

后续质量门槛应是：多位未参与开发的用户独立完成采样；在未见词、长文、数字和复杂公式上检查准确性与相似度；OCR 结果与真人检查分别保存。程序不得把“生成成功”或“安装成功”当作字迹准确性验收。
